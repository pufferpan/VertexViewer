# 只列有网格的资产 + 改枪皮肤按套装展开

## 1. 「模型库」只列真的有网格的条目

以前只信 `work/mesh_catalog.json`：目录里没有的资产一律当「未知」放过。问题是
`_1P/_3P` 这个尾巴不止网格有，**动画序列、图集、蓝图通知全都带**，装全量 pak 后
近四成的列表条目其实是空壳，点开只有一个空视口。

现在分两层判定：

| 来源 | 判定方式 | 说明 |
| --- | --- | --- |
| `mesh_catalog.json` 里有 | 直接读类名 | `StaticMesh` / `SkeletalMesh` 才算，`AnimSequence`、`Texture2D` 直接剔 |
| 目录里没有 | 读 uasset 包头 | `core/loader.py::header_is_mesh()`，`core/meshcheck.py` 落库缓存 |

- 结果按 pak 集合指纹（`_index_stamp()`）缓存进 `index.db` 的 `meshcheck` 表；换游戏
  目录、装新包后自动整体失效重判，不会拿旧结论糊弄人。
- 首次校验在索引线程里跑，状态栏显示「校验网格 1234/8000」，UI 不冻；判过之后
  再启动直接读缓存。
- 顺带补了几个拼错的动画目录（`/anims/`、`/aimns/`、`/ainm/`、`/anm/`、`/anima/`），
  这些目录里的东西连包头都不用读就能排掉。

实测（218 个 pak 的全量安装）：候选 17,189 → 留下 **15,186** 个真网格，
「武器皮肤 6051」这类数字随之变成真实可渲染数量。

## 2. 改枪页皮肤下拉：按枪名展开整套皮肤

`core/weapon_skins.py` 原来只认「机匣部件号完全一致」，可皮肤套装是**整套换模具**
的：机匣号、配件号都和原版不同。结果 M4A1 这种枪的下拉里只有「原版」。

现在两路合并：

1. 老逻辑：部件号一致的机匣变体（严格、不会串味）。
2. 新增：按枪名键（`_gun_key()`，`rec_ar_m4a1-std_001 → m4a1`）把
   `Commerical/WeaponAppear/<批次>/<皮肤>/<枪>/` 下所有套装收进来，用套装自己的
   机匣当主件（`cross=True` 标记「跨号套装」）。

跨号套装的配件配对走 `_kit_part_for()`：部件号严格匹配不到时，按槽位（枪管/护木/
枪口/…）在套装目录里找同名片段最多的那一件；同号套装缺件时同样补这一手，避免
「换了皮肤只有机匣变色」。同号且能对上的配件仍走严格匹配，不受影响。

顺带修了左栏布局：「应用皮肤」原来和下拉挤在一行，左栏一窄按钮只剩半个「应」字，
根本点不到。现在按钮单独一行。

实测：67 把主件枪的皮肤总数 312 → 328，其中原本只有「原版」的 M4A1 现在有 8 项
（原版 + 7DL9D_9r / A0874_n8 / DragonsCastle_s3 / HavvkTech_p9 / InterArm_3w /
Labotory_w7 / Transparent），QBZ95、MCX 各 +5。
