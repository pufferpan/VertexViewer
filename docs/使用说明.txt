VertexViewer · 模型浏览器 —— 使用说明
================================================

一、怎么启动
------------
1. 把整个 VertexViewer 文件夹解压到硬盘（别只解出 VertexViewer.exe，它旁边那个
   _internal 文件夹是它的运行库和数据）；
2. 双击 VertexViewer.exe；
3. 第一次启动如果没自动找到游戏，会弹窗让你选该游戏的安装目录
   （选到有 DeltaForce 文件夹的那一层，例如 D:\Games\Game）；
   选过的目录会记下来，下次不用再选。
   想换目录：左上角「打开游戏目录」按钮。

二、需要什么
------------
- Windows 10 / 11 64 位（用的是 OpenGL 3.3 视口）；
- 电脑上装了该游戏（模型和贴图从游戏 pak 里实时读，本软件不含游戏资源）；
- 不需要装 Python，不需要 .NET，运行库都打在这个文件夹里了。

三、里面有什么
--------------
- 改枪皮肤：选好主件，在「枪械皮肤」中选择外观并点「应用皮肤」。
  勾选「同步官方皮肤配件」会切换到该皮肤的官方配置；关闭后保留手选配件和位置。
  不存在对应外观的配件保留原版，选「原版」可还原，保存方案会一起保存皮肤。
- 改枪分部件导出：点「导出 OBJ」后可选合并导出或按槽位分部件导出。
  分部件导出会新建独立文件夹，保存主件/配件各自的 OBJ、MTL、贴图与 JSON 清单；
  部件已带装配位置，可一起导入三维软件，清单记录来源、挂点及变换。
- 感谢名单：从「设置」底部打开，使用首次向导的蓝色背景与展开动画。
  已收录 10 位朋友的姓名与留言，按拼音或英文字母排序，GitHub 链接可点击打开。
- 9397 个模型资产（武器 / 配件 / 装备 / 弹药 / 钥匙卡 / 藏品 / 容器 / 角色
  / 角色技能 / 载具 / 道具 / 其他，共 13 类）；
- 中文名 9933 条：来自游戏 DataTable + StringTable(.ustbin) + locres 三源合并；
- 检视 / 把玩动画：模型库默认只显示可检视模型，选中后点击「检视当前模型」播放对应的骨骼动画；
- 材质页可以把整套网格换成某一个材质（有些 1P 包只有 1 个分段、多材质，用它手动看）；
- 导出：OBJ（含 mtl + 贴图）、自研 .uemodel、FModel 目录格式；
- 图标：优先用游戏里的 UIIcon（有就最准）；没有游戏目录时用**随包的图标库**
  （安装目录 _internal 下的 dfdata 里，1204 张，别人电脑上也有图）。
- 自定义图标：卡片右键「设置图标」，表存在 work\icon_table.json，
  底部「图标表」还能导出一份分享包发给别人。

四、数据和缓存放在哪
--------------------
- 资产索引：**一个 SQLite 文件**，固定在 %LOCALAPPDATA%\VertexViewer\index.db。
  它的位置不随安装目录变化，也不会被清缓存删掉；第一次启动会自动从游戏
  pak 扫出来（约 1 分钟，有进度条），以后每次启动都是秒开。
- 静态查表数据（中文名 names.json、动画表 mesh_catalog.json、密钥 AESKey1.json、
  pakinfo.json）随包放在 exe 旁边的 data\ 里，想替换直接覆盖同名文件；
  也可以用环境变量 VERTEXVIEWER_WORK 指向别的目录。
- 解包缓存、日志、导出的 .uemodel 在 %LOCALAPPDATA%\VertexViewer\（cache / logs / uemodel）。

五、常见问题
------------
- 模型库是空的 / 提示没有可用索引：多半是没选游戏目录，或游戏版本更新后
  pak 变了 —— 进「设置 → 数据维护」点「重建索引」即可，不用重装、不用找文件；
- 某个模型提示「它的 1P 包只有壳没有几何」：软件会自动换 3P/LAY 变体再读；
- 贴图糊、没有贴图：这类 VM（虚拟材质）资产的贴图不写在材质里，游戏内由
  Runtime 拼，离线只能看到素模；
- 视口全黑：显卡驱动太老（需要 OpenGL 3.3），换台机器或更新驱动；
- 快捷键：Ctrl+O 打开游戏目录、Ctrl+E 导出当前模型、F5 抓图、
  F11 全屏、Ctrl+R 重置视角、Ctrl+F 跳到搜索框。

六、注意
--------
本工具只读游戏文件、不做任何修改；模型与贴图版权归游戏厂商所有，
导出的资源请只用于个人学习/研究，不要商用或二次分发。


启动过程
  双击后会先在屏幕正中显示一个小方框（300×168，直角、无圆角、毛玻璃半透明），
  左边有个转动的蓝色小圈，右边写着当前阶段和真实进度：
    · 正在装载资产索引 · 340000/937088 个资产
  右下角落款：软件制作：河豚潘 PufferPan
  索引装完，这个方框会**以中心为基准**放大展开成程序主窗口（约 0.66 秒，
  最后 130ms 交叉淡出），不会往角落跑。
  Windows 上会用 DWM 的 acrylic 毛玻璃（Win11 再加一层系统背板）；
  系统不支持时自动退回实心深色底板，不影响启动。
  第一次启动如果找不到游戏目录，会在这之后弹出目录选择框。

  数据目录：索引不在包里了 —— 它是 %LOCALAPPDATA%\VertexViewer\index.db 一个
  SQLite 文件，第一次启动自动从游戏 pak 生成，之后一直复用。

【出问题怎么求助（诊断报告）】
  设置 → 数据维护 → 「生成诊断报告」：它会把版本号、程序/数据目录、每个数据文件
  找到的是哪一份、索引数据库状态、条目数、中文名条数、配置、以及
  最近一次启动日志的结尾，全写进一个 txt（同时弹窗可「复制全文」）。
  报告里没有游戏文件内容，也不联网，直接整段发给作者就能定位。
  另外：程序崩溃时会在 %LOCALAPPDATA%\VertexViewer\logs\ 下自动留一份
  「崩溃-时间.txt」，里面同样带完整诊断信息。

【换电脑 / 索引没了怎么办】
  - 什么都不用找：直接开软件，它会自己扫游戏 pak 把 index.db 建出来（约 1 分钟）。
  - 想手动重建：进「设置 → 数据维护」点「重建索引」，有进度条，完成后不用重启。
  - 想清干净就点「恢复出厂设置」（清缓存/配置/自定义图标，索引默认保留；
    勾「连索引一起删」才会连 index.db 一起删）。
  - 「打开数据目录」能直接看到 data\ 里有哪些静态数据文件。

【教程页】
  左边导航「教程」——这一版内容先写「敬请期待」（图文教程还在做）；
  进场动画和启动时那块加载卡片是同一套（760ms OutCubic 放大），
  右上「重播动画」可以再看一遍。

【启动画面】
  弹出一张带 logo 的小卡片（缩放+淡入），状态文字和进度条随后从下/左「拉出」；
  索引读完会先把进度条拉满、显示「请享用这款软件吧！」，然后把卡片放大成
  主窗口大小再淡出。进度条走的是真实数据（正在装载资产索引 · N/937088 个资产），
  并且是平滑追着目标值长过去的，不会一格一格跳。

【首次启动】
  第一次打开会自动停在「教程」页并放一遍进场动画（卡片从小放大，和启动卡同款参数）。
  之后就是普通启动，不会再动画，也不会强制跳教程；想再看点教程页右上「重播动画」。
  想手动重置这个「首次」标记：删掉 %LOCALAPPDATA%\VertexViewer\config.json 里的 tutorial_seen
  （或者设置 → 数据维护 → 恢复出厂设置）。

【界面组件库】
  界面强制使用 XDDXMT 的 FluentPy（包名 fluentpy-qt，文档 https://fluentpy.mcxmcl.cn ）；
  已经随安装包一起带上，别人电脑不用另装。设置页「渲染器与资产」里那行
  「Fluent 组件」会写明当前用的是哪一版。
  qfluentwidgets（PySide6-Fluent-Widgets）已经从项目里整套删掉，不再作为回退；
  只有显式设置 VERTEXVIEWER_FLUENTPY=0 才会用程序内自绘的仿制界面（离线救急）。


新增：启动音乐（2026-11-04 startup-audio）

- 启动时播放 OPEN_0 音乐一次；界面展开后继续播完，关闭软件时停止。
- 音频随 EXE 和便携包提供，不依赖桌面路径；自动验证模式不播放音乐。

修复：物品检视方向（2026-11-04 item-root-orientation）

- 根据每件物品的真实骨架根参考变换修正手部挂接，避免根旋转重复叠加。
- “纵横”等自带旋转根骨骼的物品与手指位置、朝向对齐；整枪和配件保留原有装配。
- 动画 GLB 导出包含同一挂接修正，单独导出物品时保留其原始坐标。

新增：第一人称检视与改枪动画（2026-11-04 first-person-gunsmith）

- 检视默认使用游戏里的第一人称相机挂点，镜头跟随动作，保留原有手持方向。
- 播放栏可以切换「第一人称 / 自由观察」。第一人称下滚轮可调整视角范围。
- 改枪完成后点击底部「检视整枪」，当前皮肤、配件和手动位置会一起参与检视。
  弹匣等配件绑定到对应的运动骨骼；可在预览上方切换检视动作。
- 点击「返回装配」继续改枪；修改装配时会自动退出检视，避免旧动画覆盖新方案。
- 改枪检视里同样可以导出 GLB，包含当前装配、手臂、动画和第一人称相机。

新增：角色手臂检视与动画导出（2026-11-04 inspection-hands-export）

- 在模型库选择模型，打开「检视当前模型」，有配套动作时会自动显示角色手臂。
- 「角色手臂（播放 / 导出）」默认开启；关闭后可单独查看和导出物品。
- 点击「导出当前动画 · GLB」，选择保存位置，导出当前选中动作片段。
  GLB 内含模型、贴图、骨骼、权重和原始帧率动画，可通过 Blender 的 glTF 导入器打开。
  有手臂时会一并导出手臂动作与物品挂接关系，无须手动对齐。
- 游戏没有提供可匹配手臂资源的动作会显示说明，仍可播放、导出物品自身动作。
- 多段动作通过播放栏右侧列表选择，再分别导出；播放倍速不改变导出帧率。

新增：检视动画与扩展配件（2026-11-04）
--------------------------------------
- 检视动画：在模型库选择可检视模型，点击「检视当前模型」即可播放该物品
  当前目录及子目录中的真实动作。支持播放/暂停、拖动时间轴、调速和循环。
  UI/Lay 静态模型会尝试切换到同组中骨骼匹配的模型；检视页只列出已验证
  可播放的匹配动作，可以在列表中搜索名称。
- 改枪位置：右侧的位置、旋转和缩放数字均可直接输入；支持四位小数和滑块范围
  外的值。切换配件、保存方案不会把手动输入的值重新取整。
- 战术设备：已补全 Dev 类设备和其他变体。槽位「选」用于替换，点击「添加更多
  配件」可从游戏模型或本地配件库追加，能够同时装镭指和手电。右侧可切换挂点，
  CommonL_point / CommonR_point 通常为左右导轨，实际位置取决于枪械现有挂点。
- 导入本地配件：支持 OBJ、GLB、glTF、STL、PLY 和未压缩 UEMODEL。选择单位
  和向上轴后导入，模型与贴图保存在 %LOCALAPPDATA%\VertexViewer\custom-parts，
  此后移动原文件不影响使用。跨电脑迁移方案时请一并复制 custom-parts 文件夹。
- 导入后可手动调整位置、旋转、缩放与挂点，点击「移除选中配件」只移除当前一件。


可检视筛选更新（2026-11-04 inspectable-only）
------------------------------------------------
- 模型库默认勾选「只显示可检视模型」，搜索、分类、卡片和目录视图都会同步过滤。
- 检视页「选择模型」只列出可检视模型；动作列表只显示已验证可播放的动作。
- 其他物品的骨骼动作、需要基础姿势的叠加动作和单帧姿势不会混入列表。
- 首次启动会核对模型与动画的骨骼关联并缓存，游戏更新或重建索引后会重新核对。
- 如需浏览完整模型库，可取消勾选「只显示可检视模型」。


检视与模型联动更新（2026-11-04 inspection-linked）
------------------------------------------------
- 在模型库点选模型后，检视页会立即切换为该模型的动作列表，无须手动同步模型。
- 模型库右侧「检视当前模型」可直接进入检视页，并自动加载可播放的对应动作。
- 在检视页选择其他模型，也会同步模型库的当前选择；单击动作即可切换播放。
- 切换模型会清除上一个模型的动作和预览，快速连续点击以最后选择的模型为准。
- 不再提供混合全部物品的动画选择器；同目录下属于其他物品的动作会过滤掉。
- 无对应动画的模型会明确显示没有动画；不会继续显示上一个模型的动作。

取消激活（2026-11-10 no-activation）
------------------------------------
- 不再需要激活码，启动即用；没有机器码、没有有效期、没有联网校验。
- 旧版本留下的 activation.json 不再读取，删不删都行。
- 本版本不再包含任何签发/校验代码与公钥配置。
