## 材质白层

默认 game 样式此前重复增加了环境反射、白色边缘和固定亮底；直接漫反射又把 Lambert 的 `1/PI` 抵消，使材质整体偏白。现在修正 GGX 粗糙度与漫反射能量分配，去掉重复的 game 补光/反射/常量抬亮，默认关闭 bloom。保留基础材质高光、高清贴图及 UV/法线修复。

`render/verify_material_lighting.py` 的线性 framebuffer 检查证明：无灯光、无环境时由旧版 RGB 0.0039978 改为 0；标准漫反射与理论值误差小于 0.00005；纯黑材质仍保留正常介质反射。实际 M4A1 对比在 `work/fix-20261101/lighting/`。

## 枪械皮肤

改枪页增加皮肤选择和“同步官方皮肤配件”选项，默认同步该套皮肤的官方装配。关闭后仅替换对应部件的外观，并保留当前配件和手调变换。皮肤依据完整机匣/部件编号匹配，商业皮肤限定同套、同枪目录；未收录的新皮肤读取 uasset header 确认网格类型。界面显示真实资产皮肤代码，不猜中文译名。

`Recipe.skin_id/skin_base` 和 `PartSpec.skin_source` 兼容旧方案 JSON。更换皮肤、还原原版和保存/读取方案保留来源关系。索引重建会清理皮肤缓存。

官方装配只加入有预设实例或可验证挂接依据的部件，避免把目录中独立辅助网格也当成默认装配。已有配件实例保留各自 socket，覆盖同一导轨盖在多个挂点的情况。

用户提供的 RAR5 内附 `source_patch/part_export.py` 和作者说明。RAR 格式不受当前 REA 归档读取器支持，因此使用已有 7-Zip 26.02 提取这两份补丁及说明，未运行外部 EXE。源文件及压缩包 SHA-256 在 `work/features-20261101/reference-provenance.json`。

将导出实现直接集成到 `exporters/part_export.py` 与改枪页，未采用运行时类替换。点击“导出 OBJ”可选择合并或按槽位分部件导出。后者写入新的独立文件夹，每个部件分别有 OBJ/MTL，贴图共享目录但使用部件前缀防止同名覆盖，并生成记录来源、挂点、矩阵、旋转、偏移、缩放和失败项的 JSON 清单。

部件导出的变换顺序与预览装配相同：父件/挂点世界矩阵、默认伸展、用户偏移、旋转、缩放。几何已经烘焙到装配位置，可在三维软件中一起导入。
