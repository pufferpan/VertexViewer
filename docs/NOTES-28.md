# 2026-11-01 · fix4 枪械配件破面与皮肤实装

保留关闭皮肤的 fix3 独立构建及 ZIP；本次在 fix4 恢复皮肤入口。

## 配件扭曲根因

`core.mesh._locate_leading_container` 原来只检查模 4 为 0/2 的计数字段。虚拟文件包含长度不定的 uasset 头，武器配件的 LOD 索引计数也会落在奇数偏移。漏掉本件前置索引后，后续扫描可能把下一档 LOD 的索引套在本件顶点上；这些索引仍在顶点范围内，因此单纯检查越界或有限坐标无法发现。

现在检查四种字节对齐，并要求索引数据精确结束于当前位置缓冲头，禁止整数除法把差一字节的候选当作命中。没有通过删除面或拉平几何掩盖错误。

实际前握把 FroG_Pic_Mag-AFG_003：修复前错误使用 240 面，修复后恢复 488 面，面法线与顶点法线的中位点积从 0.015 恢复至 0.987。KAC 导轨盖从 236 面恢复至 408 面，CoreCP 枪托从 353 面恢复至 762 面。

原始解析器来源、SHA、前后数据和真实 OpenGL 图片在 `work/features-20261101/index-fix/`。多个枪族共 68 个机匣/配件抽查数据在 `geometry-audit.json`。这仍是抽样验证，并非遍历游戏全部模型。

## 皮肤与材质

改枪页启用皮肤选择和“同步官方皮肤配件”，支持原版还原、保存/读取方案。匹配完整部件编号及同枪皮肤目录，保留无对应皮肤的手选件；实际挂接按唯一可验证的父件 socket 解析。

修复同槽位多个导轨盖在右侧选择后仍编辑第一件的问题，变换控件现在绑定实际配件实例，列表补充挂点名称。

材质加载保留本地完整路径，避免同名实例串到其他枪械目录。读取父材质默认静态开关；子实例覆盖优先，兼容 `Value`/`ParameterValue`，布尔值从标签读取。关闭的自发光开关不再启用储存的颜色，当前父材质没有引用的遗留自发光参数也不再抬亮整件。HK416 RecordAction 的实际 `UseEmissiveColor=1`，从本机匣 `Texture/HD` 读取其 EmissiveMaskMap，保留局部官方绿色发光。自发光贴图按遮罩调制颜色，消除重复常量叠加。

皮肤枪托沿用同编号原版的明确伸展校准；有冲突的多个校准来源不猜测。用户的手调偏移保持独立。

M4 标准 001 枪托本身带完整圆筒，其前缘在原始 socket 处误差仅 0.17mm。撤销由错误 Boss 预设拟合的 -71.3mm 整体位移，消除枪托与机匣之间的空隙。HK416C 的 041 后圆筒与 089 导杆/托底板是分开的网格，按已选 041、同套对应 089 及机匣确有 `416cPart_point` 的条件补齐。
