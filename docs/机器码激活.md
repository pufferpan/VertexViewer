# 模型查看器机器码激活

启动后先输入 `DFVA1.` 开头的激活码。机器码以 `DFV1-` 开头，与地图导出器区分。
一个码包含软件名称、本机机器码、授权名称、签发时间和到期时间，以上内容一起
使用 Ed25519 签名。名称、时间或机器码被修改后，签名校验不会通过。

激活后，在「设置 → 激活与授权」查看授权名称及时间，复制机器码，或更换激活码续期。
到期后启动会要求重新激活；保持软件打开时也会检查到期时间并锁定界面。
运行时结合单调时钟检查经过时间，并记录上次使用时间，检测明显的系统时间回退。
离线校验依赖本机时间，不能替代在线可信时间服务或阻止修改客户端程序。

签发网页：https://dfmap-activation-console.jfding-ecnunic.chatgpt.site/?product=VertexViewer

网页仍仅管理者可访问。选择原有 `owner-signing-key.pem`，输入模型查看器机器码，
填写授权名称，选择 7/30/90/365 天、自定义到期时间或永久授权，复制生成的码即可。
自定义时间按签发电脑的本地时区转换，码中存储 UTC 秒时间戳，使用者电脑按自己的
本地时区显示。私钥只在浏览器内存中使用，不上传，不保存到网页。

原有密钥在本机「文档/AtlasMap-Activation/owner-signing-key.pem」，
应单独备份。软件和便携 ZIP 仅包含公钥；不包含私钥和签发权限。

离线备用签发：

```powershell
python tools/activation_owner.py --private-key <私钥路径> --machine <机器码> --name "授权名称" --days 30 --out 激活码.txt
```

也可用 `--expires "2026-12-31T23:59:59+08:00"` 或 `--forever` 替代 `--days`。
本机激活记录保存在 `%LOCALAPPDATA%/VertexViewer/activation.json`，到期后用新码覆盖续期。
本功能与地图导出器各自校验授权，原地图导出器的激活码继续有效。
